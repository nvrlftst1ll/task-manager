# Перенос дизайна Task Manager в Figma

Кит для переноса дизайна приложения в Figma. Важно понимать ограничение:
**REST API Figma доступен только на чтение** — извне нельзя ни создать
файл, ни записать в него слои (это ограничение самой Figma, а не прав
доступа). Поэтому перенос оформлен тремя способами, все они дают
редактируемые слои в вашем аккаунте.

## Состав кита

| Путь | Что это |
|---|---|
| `plugin/manifest.json` + `plugin/code.js` | Плагин для Figma: рисует 7 экранов приложения авто-лейаутом и точными токенами из `global.css` |
| `design-tokens.json` | Дизайн-токены в формате Tokens Studio: наборы `light`, `dark`, `core` |

## Способ 1 (основной): плагин-генератор — дизайн появится в Figma отдельным файлом

1. Откройте [figma.com](https://figma.com) или Figma Desktop.
2. **File → New design file** — новый пустой файл (он и станет отдельным
   файлом с дизайном; сохранится в вашем Drafts).
3. Меню (Figma → **Plugins → Development → New Plugin…**).
4. Выберите **Figma design plugin → Link to existing plugin** — и укажите
   папку `task-manager/figma/plugin` (с `manifest.json` и `code.js`).
5. Правый клик по холсту → **Plugins → Development → Task Manager —
   Design Generator**.
6. Готово: появится страница **«Task Manager — UI Kit»** с семью экранами:
   - Board / Light и Board / Dark — канбан-доска (title bar, поиск,
     фильтры, 3 колонки с карточками);
   - Modal / Новая задача (light) — форма с валидацией и тегами;
   - Modal / Детали задачи (dark) — детали со сменой статуса;
   - Settings / Настройки (dark) — темы, уведомления, хоткеи, экспорт;
   - Onboarding / Первый запуск (light) — выбор темы, хоткеи;
   - UI Kit / Компоненты — кнопки, чипы, переключатели, kbd, тосты,
     карточки с полосами приоритета, статусы.

Слои именованы по семантике приложения (`TaskCard / …`, `segmented / …`),
карточки и списки собраны auto-layout'ом — их можно редактировать как
обычные фреймы Figma. Ничего не отправляется в сеть.

## Способ 2: дизайн-токены (Tokens Studio)

1. Установите бесплатный плагин **Tokens Studio for Figma** (Figma
   Community).
2. Откройте его в любом файле → вкладка **Tokens** → шестерёнка
   (Settings) → **Import** → выберите `design-tokens.json`.
3. Появятся наборы `light`, `dark`, `core`: цвета обеих тем, радиусы,
   отступы, типографика, размеры контролов, тени. Переключение тем —
   через наборы `$themes` внутри файла (Light = light + core,
   Dark = dark + core).

Токены извлечены 1:1 из `src/styles/global.css` — значения совпадают с
реальным приложением, включая текст primary-кнопки в тёмной теме
(`#052e21` на изумрудном фоне).

## Способ 3: блок-схема user-flow.html (Часть 1) через html.to.design

1. Установите плагин **html.to.design** (Figma Community).
2. Скачайте `user-flow.html` из ZIP-архива проекта (или кнопкой на
   витрине доставки).
3. В Figma: запустите html.to.design → **Import from HTML/file** →
   загрузите файл — блок-схема станет редактируемыми слоями.

## Почему не автоматически

Инструменты интеграции Figma (REST API) умеют только читать файлы,
рендерить изображения и оставлять комментарии — записи дизайна в API
нет ни у одной роли. Плагин, запущенный внутри Figma, — официальный
способ создавать слои программно, поэтому генератор оформлен именно
так: один запуск в пустом файле — и дизайн у вас, в отдельном файле
вашего аккаунта.
